# index.html 작업 규칙

## 토큰
- 색·간격·크기·시간 값은 `work/seoul-parking/tokens.json`(system 승인본)에서 온다. `:root` 변수와 스크립트의 `T` 객체가 그 사본이다.
- 새 값을 직접 쓰지 말고 기존 semantic 변수(`--color-*`, `--size-*`, `--d-*` 등)를 쓴다. 맞는 토큰이 없으면 지어내지 말고 알린다.
- 채도 있는 색은 빈자리 기둥(데이터)에만 쓴다. 화면 틀(검색창·버튼·시트)은 무채색.
- 기둥 색은 빈자리 비율 구간(`--column-*`)이고, 색만으로 구분하지 않고 숫자 라벨을 같이 보인다.

## 문구
- 모든 화면 문구는 `work/seoul-parking/copy.json`을 따른다. 합니다체, 버튼 8자 이하, `banned` 목록 단어 금지("!", "오류가 발생", "운전 중" 등).
- 표기 형식(기준 시각, 빈자리, 요금, 운영시간, 주소 끝 " 0" 제거, "지도 위치 없음")은 `copy.json`의 `rules`를 그대로 쓴다.
- 숫자는 천 단위 쉼표 없이, `tabular-nums`.

## 데이터 계산
- 빈자리 = `total − parked`(0 미만이면 0). 기둥 높이는 빈자리의 제곱근에 비례, 1대 이상이면 최소 높이, 0은 바닥 원판.
- 오래됨 기준은 `T.staleAfterMin`(20분) 한 곳에서만 정한다.
- 좌표 없는 주차장은 지도에 기둥을 세우지 않고 목록·검색에만 보인다.

## 상태·접근성·동작
- F8 필수 상태(불러오는 중, 실패+재시도, 검색 결과 없음, 위치 권한 거부, 화면 안에 주차장 없음, WebGL 없음 → 목록으로 시작)를 깨뜨리지 않는다.
- `prefers-reduced-motion`에서는 카메라 비행·솟아오름 연출을 끄고 `--d-*` 축소값을 따른다. 새 애니메이션도 같은 분기를 거친다.
- 터치 대상은 `--size-touch`(44px) 이상. 기둥·버튼에 접근성 이름을 둔다(예: "빈자리 {n}면").
- 데이터에서 온 문자열을 `innerHTML`에 넣을 때는 `esc()`를 거친다.
- 하단 출처 표기("서울 열린데이터광장", "© OpenFreeMap © OpenMapTiles © OpenStreetMap contributors")를 지우지 않는다.

## 외부 의존
- MapLibre는 버전을 고정해(`maplibre-gl@5.24.0`) 쓴다. 올릴 때는 CSS·JS를 같이 바꾼다.
- 바탕 지도는 OpenFreeMap(키 없음). 키가 필요한 지도·서비스를 추가하지 않는다.
- 길찾기는 외부 지도 앱 링크로만 넘긴다.
