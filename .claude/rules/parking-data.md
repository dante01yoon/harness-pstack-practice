# 주차장 데이터 규칙

출처: 서울 열린데이터광장 OA-21709 `GetParkingInfo`. 응답 모양은 `{ GetParkingInfo: { list_total_count, RESULT, row: [...] } }`.

## data/parking.json
- 2026-10-26에 실제로 호출해 저장한 응답이다. 손으로 고치거나 행을 지어내지 않는다.
- 새로 받을 때는 Open API를 다시 호출해 통째로 바꾸고, 응답에 인증키가 섞이지 않았는지 확인한다.
- 시험용으로 오래됨·만차 같은 상태가 필요하면 이 파일을 고치지 말고 별도 파일이나 코드 안에서 만든다.

## 필드 해석
- 식별자는 `PKLT_CD`(122곳, 중복 없음). 구는 별도 필드가 없어 `ADDR` 첫 단어에서 얻는다.
- 실시간 여부는 `PRK_STTS_YN === '1'`. 이때만 빈자리 = `TPKCT − NOW_PRK_VHCL_CNT`. `0`이면 빈자리를 계산하지 않는다(현재 13곳).
- `NOW_PRK_VHCL_UPDT_TM`은 `'YYYY-MM-DD HH:MM:SS'` KST. 시간대 없이 `new Date()`로 읽지 말고 `+09:00`을 붙여 해석한다. 화면 표시도 `Asia/Seoul` 기준.
- 오래됨: 현재 시각 − `NOW_PRK_VHCL_UPDT_TM` > 20분(PRD F6에서 확정, `STALE_MS`).
- 운영시간 `'0000'~'2400'`은 24시간, 시작과 끝이 같으면(`'0000'~'0000'`) "정보 없음".
- `DAY_MAX_CRG`가 0이면 일 최대 요금 줄을 그리지 않는다("없음"이라 쓰지 않음).
- 버스전용은 `OPER_SE_NM === '버스전용 주차장'`. 요금은 `BUS_` 접두 필드를 쓴다.
- `'*'`와 빈 문자열은 값 없음으로 본다.
- 숫자 필드는 `1260.0`처럼 실수로 오므로 `Number()`로 바꿔 쓴다.

## 서버(프록시)를 만들 때
- 인증키는 `process.env.SEOUL_OPENAPI_KEY`에서만 읽는다. 클라이언트 응답·에러 메시지·로그·리다이렉트 URL에 키나 키가 든 요청 URL을 넣지 않는다.
- Open API는 1회 최대 1000건씩 끊어 부른다. 지금은 122곳이라 한 번(`/1/1000/`)이면 된다.
- 응답의 `RESULT.CODE`가 `INFO-000`이 아니면 실패로 다룬다. 화면은 이미 받은 목록을 유지하고 error 상태를 보여 준다.
- 브라우저에는 지금 화면이 읽는 것과 같은 모양을 돌려주어 `index.html`의 `DATA_URL`만 바꾸면 되게 한다.
