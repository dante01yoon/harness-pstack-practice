# seoul-parking

## 목표
출발 전에 휴대폰 웹에서 목적지 근처 서울시 공영주차장의 빈자리를 바로 확인한다.
첫 화면은 3D 지도다. 주차장마다 빈자리 수만큼 솟은 기둥으로 "어디가 비었나"가 한눈에 보인다.
화면은 딱딱하지 않게 움직이고 손으로 만지며 탐색하는 인터랙티브 화면으로 만든다.

- 판단에 걸리는 시간: 앱을 열고 목적지 근처 빈자리 수를 읽기까지 10초 이내
- 신뢰: 모든 숫자 옆에 기준 시각을 둔다. 기준 시각이 20분을 넘으면 "오래됨"으로 구분해 보여 준다.

## 사용자
- 주 사용자: 출발 전에 목적지 근처 공영주차장 빈자리를 확인하는 운전자
- 쓰는 상황: 집·사무실에서 출발 직전, 또는 정차 중 동승자가 휴대폰으로 확인한다. 한 손 조작, 짧은 시간.
- 운전 중 조작은 전제하지 않는다. 화면 문구에 운전 중 사용을 권하지 않는다.
- 알고 싶은 것: ① 빈자리가 있나(몇 대) ② 그 숫자가 언제 기준인가 ③ 요금과 운영시간

## 기능
- F1: 3D 지도 첫 화면 — OpenFreeMap 바탕 지도에 3D 건물을 켜고, 주차장마다 빈자리 수(총 주차면 − 현재 주차 대수)가 많을수록 높은 기둥을 세운다. 높이는 빈자리 수의 제곱근에 비례하고(큰 주차장 하나 때문에 나머지가 납작해지지 않게), 빈자리가 1대 이상이면 최소 높이를 준다. 빈자리 0은 바닥 원판. 정확한 숫자는 기둥 위 라벨로 읽는다. 기둥 색은 빈자리 비율 구간으로 나눈다.
- F2: 움직이는 탐색 — 손가락으로 끌기·두 손가락 회전·기울이기. 처음 열 때 서울 전체에서 사용자 위치(허용 시) 또는 시청 근처로 카메라가 날아가며 기둥이 바닥에서 솟아오르는 짧은 연출. 데이터를 새로 받으면 기둥 높이가 부드럽게 바뀐다. 동작 줄이기 설정(prefers-reduced-motion)에서는 연출을 끈다.
- F3: 주차장 상세 — 기둥이나 목록 항목을 누르면 아래에서 시트가 올라온다. 이름, 주소, 빈자리/총 주차면, 기준 시각(오래됨 표시), 기본 요금(분·원), 추가 요금, 일 최대 요금, 평일·토요일·공휴일 운영시간, 유무료, 전화번호. 길찾기는 외부 지도 앱 링크로만 넘긴다.
- F4: 목록 보기 — 지도와 목록을 전환한다. 목록은 현재 지도 화면 안의 주차장을 거리순(위치 허용 시) 또는 빈자리순으로 정렬한다. 지도와 같은 데이터·같은 기준 시각을 쓴다.
- F5: 검색 — 주차장 이름과 자치구 이름으로만 찾는다(예: "세종로", "종로구"). 주소·장소명·POI 검색은 하지 않는다. 결과를 누르면 지도가 그 주차장(또는 구 전체)으로 이동한다.
- F6: 기준 시각과 오래됨 — 주차장마다 NOW_PRK_VHCL_UPDT_TM을 기준 시각으로 보인다. 지금 시각과 20분 넘게 차이 나면 "오래됨" 상태: 기둥을 흐리게, 숫자 옆에 오래됨 표시. 실시간 연계가 없는 주차장(PRK_STTS_YN ≠ 1)은 빈자리 숫자를 보이지 않고 "실시간 정보 없음"으로 구분한다.
- F7: 새로고침 — 화면을 다시 열거나 새로고침 버튼을 누르면 실시간 데이터를 다시 받는다. 받는 중·실패 상태를 보인다.
- F8: 필수 상태 — 불러오는 중, 불러오기 실패(재시도), 검색 결과 없음, 위치 권한 거부(시청 근처로 시작), 화면 안에 주차장 없음, 3D를 못 그리는 기기(WebGL 없음 → 목록 보기로 시작).

### 데이터 결합과 실제 수치 (2026-10-27 확인, 실제 API 응답 기준)
- `GetParkingInfo`: 122곳, 23개 자치구. 이 중 실시간 연계(PRK_STTS_YN=1) 109곳, 연계 없음(0) 13곳. 유료 112곳, 무료 10곳.
- `GetParkInfo`: 2,181행, 이 중 LAT·LOT가 0보다 큰 행 1,456행. 좌표가 0.0인 행이 있다.
- 결합 키는 `PKLT_CD`. 실시간 122곳 중 117곳이 좌표 있는 안내 정보와 연결된다. 연결되지 않는 5곳은 지도에 기둥을 세우지 않고 목록·검색에서만 "지도 위치 없음"(주차장 좌표가 원자료에 없음)으로 보인다.
- 빈자리 = `TPKCT − NOW_PRK_VHCL_CNT` (0 미만이면 0). 기준 시각 = `NOW_PRK_VHCL_UPDT_TM` (한국 시간).
- 요금·운영시간: `BSC_PRK_CRG`/`BSC_PRK_HR`(기본 요금/분), `ADD_PRK_CRG`/`ADD_PRK_HR`(추가), `DAY_MAX_CRG`(일 최대, 0이면 표시 안 함), `WD_/WE_/LHLDY_OPER_BGNG_TM·END_TM`.
- 디자인 시안의 예시 숫자는 위 실제 응답에서 가져온다. 지어낸 숫자를 쓰지 않는다.

- 예약·결제·정기권 신청, 로그인·즐겨찾기 동기화
- 푸시 알림, 네이티브 앱(iOS/Android), 데스크톱 전용 레이아웃(휴대폰 웹이 기준, 데스크톱은 같은 화면을 가운데 폭 고정으로 보여 줌)
- 과거 추이·혼잡 예측 그래프
